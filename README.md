# 星座命理分析 · 手机网页版

一个**手机网页**版的命理分析产品，新中式视觉（宣纸米白 + 朱砂 + 黛青 + 真实植物叶纹），功能完整：

- **多账号 + 主账号管理**：主账号可自行添加子账号，随时停用 / 启用 / 删除。
- **多人命理档案**：任意账号（含子账号）都能录入多个不同人的出生信息并存档。
- **主账号视角**：主账号可在档案列表切换「全部（含子账号）/ 仅我的」，跨账号查看并管理子账号录入的档案。
- **三模块命理分析**：① 生辰格局（四柱纳音 + 十神格局 + 身强身弱）；② 五行分布（相生相克图 + 旺衰占比）；③ 喜用神（用神/喜神/忌神 + 幸运色/数字/石）。

技术栈：前端纯 HTML/CSS/JS，后端 Node + Express，数据存 **SQLite 文件库**（随应用部署，**免任何外部数据库配置**）。命理计算由规则引擎（基于 `lunar-javascript`）完成，非 AI 生成，已做真太阳时 + 夏令时校正。

---

## 一、本地运行（零配置，马上能看效果）

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000/login.html`（手机访问把 localhost 换成电脑局域网 IP）。

首次进入先去「注册」创建**第一个账号 = 主账号**，登录后就能用全部功能。
数据存本地 `data/mingli.db`（SQLite 文件），重启不丢。

---

## 二、上线部署（极简，免数据库）

数据库用 SQLite 文件，**不用注册 MongoDB / 不用配置连接串**，只需 GitHub + Render 两步：

1. 把本目录推到你的 GitHub 仓库（已含 `render.yaml`）：
   ```bash
   git add -A && git commit -m "deploy" && git push
   ```
2. 打开 [render.com](https://render.com) → 「New → Web Service」→ 选该仓库。
   Render 自动读 `render.yaml`：**build `npm install`、start `npm start`、免费层**。
   不用填任何环境变量（旧版的 `MONGODB_URI` 已移除）。
3. 部署完成后，Render 给一个 `https://xxx.onrender.com` 链接——手机浏览器直接打开即用。

> 免费层磁盘为临时盘，重启可能清空数据库文件；如需持久化可升级付费层，或把 `SQLITE_PATH` 指向挂载卷。演示 / 个人使用免费层足够。
